# Mobile App — Thinkxx

> React Native + Expo mobile application for the Thinkxx Lifeline protocol.

## Status: Phase 3 (Planned)

This app will be scaffolded using `create-expo-app` during Phase 3 of the project. Current focus is on the Anchor program and SDK.

## Planned Tech Stack
- React Native + Expo (managed workflow)
- TypeScript (strict)
- Mobile Wallet Adapter (MWA) for wallet connectivity
- `@thinkxx/sdk` for protocol interaction
- `@thinkxx/rpc` for network resilience
- `@thinkxx/notifications` for alerts

## Features (Phase 3 Scope)
- Wallet connection via MWA
- Plan creation wizard
- Heartbeat management
- Plan status dashboard
- Beneficiary claim flow
- Guardian approval interface
